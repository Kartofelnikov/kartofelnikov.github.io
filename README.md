# Витрина: сайты для малого бизнеса

Одна страница-витрина от имени владельца. Демо под конкретного заказчика делаются отдельно. Всё — самодостаточные HTML-файлы без сборки, открываются где угодно, в том числе во встроенном браузере мессенджеров.

| Путь | Что это |
| --- | --- |
| `index.html` | Витрина: кто я, примерка «сайт для вашего дела», как работаю, цены, заявка |
| `worker/` | Cloudflare Worker: принимает заявку с витрины и шлёт её в Telegram |

## Что заменить перед рассылкой

Всё в одном месте — блок `CONFIG` в начале скрипта `index.html`:

```js
var CONFIG={
  name:'Имя Фамилия',
  tg:'username',            // ник в Telegram без @
  phone:'+79000000000',
  phoneText:'+7 900 000-00-00',
  worker:''                 // адрес Worker после настройки
};
```

Плюс имя в теге `<title>` и двух `og:`/`meta` в шапке `index.html` (строки 6–9). Цены — в блоке `id="price"`.

## Заявки в Telegram (10 минут)

1. В Telegram откройте @BotFather → `/newbot` → придумайте имя и ник на `bot`. Он пришлёт **токен**. Никому его не пересылайте.
2. Напишите своему боту любое сообщение.
3. Узнайте свой **chat id**: напишите @userinfobot, он ответит числом `Id`.
4. Зарегистрируйтесь на dash.cloudflare.com (бесплатно) → Workers & Pages → Create → Worker → назовите `leads` → Deploy → Edit code → вставьте содержимое `worker/worker.js` → Deploy.
5. В Worker: Settings → Variables and Secrets → добавьте
   - `BOT_TOKEN` (тип Secret) — токен из шага 1;
   - `CHAT_ID` (тип Secret) — число из шага 3;
   - `ALLOWED_ORIGIN` (тип Text) — `https://nnmhj8hw8r-crypto.github.io`.
6. Скопируйте адрес Worker (`https://leads.<ваше-имя>.workers.dev`) в `CONFIG.worker`.

Проверка кода Worker без сети: `node worker/test.mjs`.

Прошлые примеры («Гербарий», маникюр, кофейня, барбершоп, студия) удалены из сайта, но лежат в истории git — их можно вернуть как заготовки для демо.
