# Демо-витрина «Мастерская сайтов»

Портфолио из четырёх демонстрационных сайтов под типовые ниши малого бизнеса + главная страница-витрина, связывающая их. Всё — самодостаточные HTML-файлы без сборки и внешних JS-зависимостей: открываются где угодно, в том числе во встроенных браузерах мессенджеров.

## Структура

| Путь | Что это | Визуальный мир |
| --- | --- | --- |
| `index.html` | Витрина-портфолио: оффер, примеры, процесс, цены | Швейцарская типографика: белый / чёрный / красный |
| `coffee/` | Кофейня-обжарщик «РОСТ»: меню, паспорт партии, подписка | «Цех обжарки»: тёмно-кофейный, молочный, огонь |
| `barber/` | Барбершоп «РУБКА»: прайс, мастера, талон на запись | Плакатный конструктивизм: красный / чёрный / бумага |
| `movement/` | Студия движения «ОСЬ»: направления, табло, журнал записи | «Анатомический атлас»: миллиметровка, чернила, коралл |
| `plants/` | Магазин растений «ГЕРБАРИЙ»: каталог, фильтры, корзина | «Гербарий»: ботанический зелёный, векторная ботаника |

Всё интерактивное реально работает на клиенте: формы валидируют и подтверждают, корзина считает сумму, слоты записи генерируются, талоны и записи сохраняются локально (в демо-режиме, без сервера).

## Перед показом клиентам

1. Замените контакты в `index.html`: `https://t.me/username` и `tel:+79000000000` (три места: шапка, hero, CTA-блок).
2. Цену «от 25 000 ₽» и сроки — подставьте свои.
3. При желании переименуйте «МАСТЕРСКАЯ САЙТОВ» на своё имя/бренд (шапка и title).

## Деплой

Статика уже опубликована на GitHub Pages из этой ветки. Локально можно открыть любой `index.html` двойным кликом.

## Честность демо

На всех сайтах стоит пометка «Демонстрационный макет»; названия, цены, отзывы и «клиенты» вымышлены. Формы никуда не отправляют данные — это витрина возможностей, а не работающий бизнес.
