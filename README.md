# Витрина: сайты для малого бизнеса

Адрес: **https://kartofelnikov.github.io** (GitHub Pages, обновляется сам при пуше в main). Копия на Cloudflare Pages — kartofelnikov.pages.dev — в России без VPN не открывается.

Одна страница-витрина от имени владельца. Демо под конкретного заказчика делаются отдельно. Всё — самодостаточные HTML-файлы без сборки, открываются где угодно, в том числе во встроенном браузере мессенджеров.

| Путь | Что это |
| --- | --- |
| `index.html` | Витрина: создаю и обновляю сайты, примерка, что делаю, как работаем, связаться |
| `worker/` | Cloudflare Worker для заявок в Telegram. На витрине сейчас не используется (связь — напрямую в Telegram), пригодится для сайтов клиентов |

## Что заменить перед рассылкой

Имя, ник и телефон — блок `CONFIG` в начале скрипта `index.html`:

```js
var CONFIG={
  name:'Марк Картофельников',
  tg:'garfild_u',            // ник в Telegram без @
  phone:'+79653770825',      // на странице не показывается
  phoneText:'+7 965 377-08-25'
};
```

Плюс имя в теге `<title>` и двух `og:`/`meta` в шапке `index.html` (строки 6–9). Цены — в блоке `id="price"`.

## Заявки в Telegram (10 минут)

1. В Telegram откройте @BotFather → `/newbot` → придумайте имя и ник на `bot`. Он пришлёт **токен**. Никому его не пересылайте.
2. Напишите своему боту любое сообщение.
3. Узнайте свой **chat id**: напишите @userinfobot, он ответит числом `Id`.
4. Зарегистрируйтесь на dash.cloudflare.com (бесплатно) → Workers & Pages → Create → Worker → назовите `leads` → Deploy → Edit code → вставьте содержимое `worker/worker.js` → Deploy.
5. В Worker: Settings → Variables and Secrets → добавьте
   - `BOT_TOKEN` (тип Secret) — токен из шага 1;
   - `CHAT_ID` (тип Secret) — число из шага 3;
   - `ALLOWED_ORIGIN` (тип Text) — адреса сайта через запятую (сейчас задаётся в `wrangler.jsonc`).
6. Адрес Worker уже вписан в `CONFIG.worker`: `https://leads.minikartoxa2105.workers.dev`. Worker привязан к GitHub и обновляется сам при пуше (настройки в `wrangler.jsonc`).

Проверка кода Worker без сети: `node worker/test.mjs`.

Старые демо (магазин растений, маникюр, кофейня, барбершоп, студия) лежат в истории git — их можно вернуть как заготовки для наброска клиенту.
